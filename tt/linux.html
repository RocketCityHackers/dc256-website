Shell Sorcery

The Magic of the Linux Command Line
DC256 × NAC-ISSA Tech Thursdays March 19, 2026 · 6:00 PM – 8:00 PM Gigaparts · Huntsville, AL

Linux isn't as scary as it seems! This crash course uses gamification to introduce you to the command line. Instead of rote memorization, you'll solve logic puzzles to master the three pillars of daily Linux work: secure access, file navigation, and data extraction.

No prerequisite knowledge required — just an open and curious mind.

Connect via SSH

$ open terminal or PuTTY, then type:
ssh bandit0@8.tcp.ngrok.io -p 11101
▸  On PuTTY, only put 8.tcp.ngrok.io and set the port number to 11101
▸  Password: bandit0
⚡ Windows users: use PuTTY (download below). macOS & Linux users: the ssh command is built in — open a Terminal and go!

Downloads & Tools

PuTTY (Windows)

Free open-source SSH client for Windows. Required if you don't already have an SSH terminal. Latest 64-bit installer:

⬇ Download PuTTY 0.83
💡 After install, open PuTTY, enter the SSH address above in "Host Name", keep port 22, and click Open.
